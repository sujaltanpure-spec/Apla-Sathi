# आपली साथ — Factory Workers Health Website

Marathi-first, mobile-friendly informational website primarily for factory workers, with a Hindi toggle and a secondary section for sugarcane/farm workers.

## Features
- Workplace health and safety guidance: PPE, heat, water, dust, fumes, chemicals, machinery, food, sleep, and symptoms
- Marathi/Hindi language toggle
- Text-to-speech for intro and topic cards
- Help guidance for factory medical room, safety officer/HR, and India emergency number 112
- Demo-only issue form (does not transmit or store information)
- Responsive mobile and desktop layout

## Open locally
Extract the ZIP and open `index.html` in a web browser.

## Publish with GitHub Pages
Upload `index.html` and this README to the root of a GitHub repository. Go to Settings → Pages → Deploy from a branch → choose `main` and `/ (root)` → Save.

## Before public launch
Have health/safety content checked by a qualified health professional or occupational safety officer. Add only verified local hospital and factory contacts. Do not collect workers' private health or identity details without informed consent and secure handling. The report form is a demo, with no backend/database. This site is not a replacement for medical or legal advice.
